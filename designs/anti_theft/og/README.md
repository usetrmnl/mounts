# TRMNL Mount - OG Anti-Theft (Public Venue)

for placement in public spaces with low supervision. incorporates a barrel lock and dovetail mechanism to prevent unauthorized removal.

### features

- 4x recessed screw holes on wall plate that fit most common fasteners
- works with generic 5/8" cam (barrel) locks (designed for [this model](https://www.amazon.com/dp/B0D72LGKTR))
- easy removal for ongoing charging and maintenance

### print instructions

DIY:

1. import STL file to any slicer tool (STEP file also provided for edits)
2. disable supports (not required)
3. ~any infill should be fine
4. PETG recommended but Basic PLA also works

Online: we hear good things about Craft Cloud:
[https://craftcloud3d.com/upload](https://craftcloud3d.com/upload)

### installation

see photos inside "preview" directory and follow along below:

1. attach back plate to a surface of your choice
2. put locking frame face down and insert OG device upside down (kickstand facing you)
3. slide cam lock into opposite side of locking frame, attach straight cam in vertical orientation
4. carefully attach locking frame to wall plate but aligning slots, then pushing locking frame downward
5. insert cam lock key and turn counter-clockwise to lock it against the wall plate's bottom hook
